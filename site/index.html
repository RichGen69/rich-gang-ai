What it is

A cinematic multi-agent AI character platform: an Android-first Flutter/Dart application with a custom Rust daemon core (libdaemon.so, FFI/JNI), where a cast of authored characters — each with personality, voice casting, an affect engine, and a persistent on-device mind — hold one-to-one conversations and agent-to-agent roundtables with sequential context passing.

Cloud AI providers (NVIDIA / OpenAI / Gemini, selectable) sit behind a circuit-breaker failover to a local Ollama path, so a blocked or rate-limited cloud account degrades the show to local instead of ending it. A self-contained HTML companion build mirrors the cast from the same character registry and is included in the diligence pack.
