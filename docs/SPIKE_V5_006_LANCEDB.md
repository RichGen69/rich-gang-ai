## Verdict
**PARTIAL PASS — spike level only.**
- Default features: **FAIL** — lancedb 0.40.0 does not compile as shipped (upstream remote-gating bug in job.rs/error.rs, proven from its own sources + two exact E0599s).
- With `remote` enabled (workaround): host functional search **PASS** (3/3 tests against the real current API, fixture vectors), Android **check PASS**, Android full build **unfinished in time-box** (no error; 361/~521 crates codegen'd at kill).
- Costs that any Tier 4 decision must price in, all measured in this spike: 521-crate lock; ~13G host debug target dir; 2.0G host debug test binary; the remote feature drags in an HTTP/gRPC cloud-client stack (axum, tonic, arrow-flight, oauth2) that a local-only store does not need; protoc is a required host build tool (now at ~/workspace/toolchain/protoc).
- Alternatives an integration decision should weigh: pin an older lancedb line that compiles without remote, wait for an upstream fix for the job.rs gating, or keep Tier 4 on the existing rusqlite store (already integrated, orders of magnitude smaller).
