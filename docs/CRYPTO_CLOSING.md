## Fixed parameters (not negotiable per-deal)

- **Coin: USDC only.** No volatile coins at this size — the price is
  $50,000, and USDC is the dollar.
- **Network: one, agreed in writing, in the APA.** Default: USDC on
  **Base** (low fees, native USDC, cleanest path into Coinbase if
  Richard later verifies there). If a buyer can only send on
  Ethereum mainnet, the APA names Ethereum instead — but ONE network
  per deal, named before any money moves. A send on the wrong
  network is effectively lost; this is the single biggest way crypto
  closings go wrong.
- **Wallet: Richard's own, on his own phone, created by him.**
  Nobody else — including Muse — creates it, holds it, or ever
  sees its recovery phrase or private key.

## Closing sequence

1. **Signed APA first** — same as the P2P protocol: asset, $50,000,
   USDC, the named network, the wallet address, delivery stages.
2. **Test transaction.** The buyer first sends a small test amount
   (e.g., $10 USDC) to the address on the named network. Richard
   confirms it arrived in his wallet. Only then does the closing
   proceed. No exceptions, no "the buyer is in a hurry."
3. **Verify on-chain, not by screenshot.** Each payment is confirmed
   by its transaction hash on a public block explorer (e.g.,
   basescan.org for Base) showing the correct amount, the correct
   destination address, and confirmed status.
4. **Staged delivery**, mirroring the P2P protocol: tranche settled
   on-chain → corresponding delivery → written acknowledgment →
   next tranche. Full source package only after the final tranche
   is confirmed on-chain.
5. **Close-out.** Bill of sale / IP assignment signed; APA, tx
   hashes, and delivery receipts kept for taxes (the income is
   taxable; USDC received is recorded at its USD value on receipt).

## After the money lands (stated now so it is never a surprise)

- USDC in a self-custody wallet is spendable as crypto immediately,
  but turning it into dollars in a bank account requires an
  exchange off-ramp (e.g., Coinbase), and that requires the
  exchange's identity verification — Richard's expired ID is the
  known blocker there. Holding USDC until the ID is renewed is the
  realistic default.
- Wallet security IS the bank security here: recovery phrase on
  paper, stored somewhere safe and offline; PIN/biometric on the
  app; any person or message asking for the phrase is a thief —
  including anyone claiming to be support, a buyer, or Muse.
